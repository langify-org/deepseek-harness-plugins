# @langify-org/dsh-browser

[English](README.md) | 日本語 | [中文](README.zh.md)

自分とモデルが共有する、DeepSeek Harness の host で動く本物の Chromium です。右サイドバーの **ブラウザ** タブにそのウィンドウがそのまま映り、自分は普通のブラウザと同じように使え、モデルは同じウィンドウを `browser_*` のツールで操作します。ブラウザは host で動くので、DSH のページを開いていないときもモデルは使い続けられ、ログインはすべての会話で共有されます。

## 必要なもの

- Web ブラウザで使う DSH `>=0.2.2-rc.1 <0.3.0-0`（DSH の Web 版）。
- DSH の host（Linux などの X11 の OS）にある次のもの：
  - [TigerVNC](https://tigervnc.org) の `Xvnc`。`PATH` にあるか、設定の `xvnc` で場所を指定します。
  - Chromium か Google Chrome。`chromium` という名前で `PATH` にあるか、設定の `chromium` で場所を指定します。
  - 開くページに合うフォント。日本語なら Noto Sans CJK、絵文字なら Noto Color Emoji など。ない文字は四角で表示されます。

Xvnc か Chromium がないときは、どちらがないかをタブに表示します。

## 導入

```sh
dsh plugin --profile <profile> add @langify-org/dsh-browser
```

DSH の Web 版では **Plugins** ページから追加できます。

## 設定

| 設定          | 既定値                               | 何か                                                                                                 |
| ------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `xvnc`        | `Xvnc`                               | Xvnc の実行ファイル。`PATH` で探す名前か、パス                                                       |
| `chromium`    | `chromium`                           | Chromium の実行ファイル。`PATH` で探す名前か、パス                                                   |
| `flags`       | `--disable-gpu`                      | プラグインが付けるものに足す、コマンドラインのフラグ                                                 |
| `language`    | 空                                   | Chromium 自身のメニューやページの言語（`LANGUAGE`）。`ja` など。空なら host のまま                   |
| `stateDir`    | `<DSH home>/browser`（bundle layer） | プロファイル・ダウンロード・アップロードを置く場所                                                   |
| `idleMinutes` | `30`                                 | 表示中のブラウザタブがなく、使われもしないまま、この分数がたったらブラウザを止める。`0` なら止めない |

## 使い方

右サイドバーから **ブラウザ** を開きます。ブラウザタブ 1 つが Chromium のウィンドウ 1 つで、Chromium 自身のタブ・アドレスバー・メニューがあります。どの会話でも、いくつでも開けます。

- **画面は 1 つ**：すべてのウィンドウが 1 つの画面を共有し、最後に表示したブラウザタブのウィンドウがそこに映ります。ほかに表示中のブラウザタブには、そう表示して **このタブを表示** のボタンが出ます。会話やタブを切り替えると、切り替えた先のウィンドウが映ります。
- **大きさ**：ウィンドウはタブの大きさになり、サイドバーの幅を変えるとついてきます。Chromium のウィンドウは 500 ピクセルより狭くならないので、それより狭いタブは横にスクロールします。
- **日本語や中国語などの入力**には、手元の端末の IME を使います。いつもどおり変換し、確定した文字がページの入力欄に入ります。ほかのキーはショートカットも含めて、キーとして Chromium に届きます。
- **クリップボード**：Ctrl+V（Cmd+V）で手元のクリップボードを貼り付けます。Chromium でコピーしたものは手元のクリップボードに入ります。ブラウザが書き込みを断ったときは、タブに **コピー** のボタンが出ます。
- **ダウンロード**：終わると、そのウィンドウのタブにお知らせが出て、**保存** で手元に保存できます。host は、次にブラウザが起動するまで残します。
- **アップロード**：ページがファイルを求めると、そのウィンドウのタブに **選ぶ…** が出て、手元のファイルを選ぶとページに届きます。
- **ログイン**は、すべての会話が共有する 1 つの Chromium のプロファイルに残ります。どのタブで一度ログインしても足ります。
- **閉じる**：ブラウザタブを閉じるとそのウィンドウが閉じ、会話を archive するとその会話のウィンドウが閉じます。ウィンドウの最後の Chromium のタブを閉じると、そのブラウザタブには新しい空のウィンドウが出ます。
- **止まる**：ブラウザは、タブかモデルが最初に必要としたときに起動し、表示中のブラウザタブがなく使われもしないまま `idleMinutes` がたつと止まります。ウィンドウは一緒に終わり、ログインは残ります。

モデルに渡るもの：

- **system prompt** で、共有のブラウザとツールについて説明します。
- **ツール**は、その会話で最後に使ったウィンドウか、呼び出しが id で指定したウィンドウを操作します。

| ツール               | すること                                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| `browser_windows`    | 会話のウィンドウとその中のタブを一覧にする。ツールが既定で使うのはどれか、自分の画面に映っているのはどれか   |
| `browser_open`       | アドレスを開く。会話にウィンドウがないときや指定したときは新しいウィンドウに開き、次に開くブラウザタブに映る |
| `browser_screenshot` | ページの画像をモデルが見る。画像を受け取れるモデルが必要                                                     |
| `browser_click`      | CSS セレクターで見つけた要素か、指定した位置をクリックする                                                   |
| `browser_type`       | フォーカスのある入力欄に文字を入力する。どの言語でもよい                                                     |
| `browser_key`        | 修飾キーと一緒にキーを押す。Enter や Control+A など                                                          |
| `browser_eval`       | ページで JavaScript を評価し、JSON の値を返す                                                                |

ダウンロードしたファイルは `<stateDir>/downloads/<id>/` にも残るので、モデルが読めます。

## 安全

- **ブラウザは sandbox の外で動く**ので、ページを変えるツール（`browser_open`・`browser_click`・`browser_type`・`browser_key`・`browser_eval`）は、sandbox の外のコマンドと同じ許可を求めます。会話が full access ならすぐ実行し、そうでなければ先に自分に確認します。ウィンドウの一覧とスクリーンショットは確認しません。確認できない subagent は、full access のときだけページを変えられます。
- **自分のログインはモデルのものでもあります**。モデルは同じプロファイルで、自分がログインしているところにログインした状態で動きます。モデルが自分として操作してもよいところにだけログインしてください。
- **ページにあるものはすべてモデルに見えます**。モデルがページを読んだときです。
- **タブの接続**は DSH 自身の API と同じく確かめます。画面を見たり入力を送ったりできるのは、この DSH にログインしたブラウザだけです。VNC は自分のユーザーしか入れないディレクトリの unix socket で待ち受け、ネットワークのポートでは待ち受けません。
- **Chromium の DevTools のポート**は、リモートデバッグの仕組みのとおり `127.0.0.1` の、Chromium が選んだポートで待ち受けます。host のほかのプログラムは、別のユーザーのものも含めて、ここにつないでブラウザを操作できます。自分しか使わない host で使ってください。
- **環境変数**：Xvnc と Chromium には、DSH 自身の子プロセスと同じく、名前に `KEY`・`PASSWORD`・`SECRET`・`TOKEN` を含むものと `DSH_*` を除いた DSH の環境変数を渡します。

## 仕組み

host のプラグインは、画面を unix socket の VNC で配る仮想の X サーバー `Xvnc`（TigerVNC）を動かし、その画面で Chromium を動かします。Chromium には `stateDir` のプロファイル、`--no-startup-window`、Chromium が選ぶ DevTools のポートを渡します。Chrome DevTools Protocol で、ブラウザタブごとにウィンドウを 1 つ作り、最後に表示したタブのウィンドウを前に出してタブの大きさに合わせ、確定した文字を `Input.insertText` で入力し、ダウンロードを保存し、ページのファイル選択を引き取ります（`Page.setInterceptFileChooserDialog`）。モデルのツールも同じ接続を使います。

ブラウザ側は **ブラウザ** タブを足します。画面は、固定の版を同梱した [noVNC](https://github.com/novnc/noVNC) で描き、専用の WebSocket（`/langify-browser/vnc`）を host が Xvnc に中継します。Xvnc の画面の大きさは noVNC がタブに合わせます。もう 1 本の WebSocket（`/langify-browser/control`）で、タブからの頼み（表示・大きさ・確定した文字）と host からのお知らせ（画面に映っているか・ダウンロード・ファイル選択）をやりとりします。キーボードは画面の上の入力欄を通すので、手元の IME が使えます。キーは noVNC の変換で VNC に送り、確定した文字は control の WebSocket で送ります。ダウンロード・アップロード・ウィンドウを閉じることには、DSH の API の決まったパスを使います。DSH はブラウザ側のプラグインを CommonJS として読み込み、noVNC の 1 か所のトップレベルの `await`（H.264 の再生ができるかの確認）はそこに入らないので、ビルドで Promise に書き換えます。noVNC がその行を変えたら、ビルドが失敗します。

## 既知の制限

- **画面は 1 つ**：2 つのブラウザタブや 2 台の端末で、別々のウィンドウを同時には映せません。
- **ページがポップアップとして開くウィンドウ**（大きさを指定した `window.open`。ログインのポップアップなど）は、そのとき表示しているタブの画面の一番上に、動かすための枠なしで出ます。ページが閉じるか、Ctrl+W で閉じます。
- **IME で確定した文字はページにだけ入り**、Chromium のアドレスバー・メニュー・ダイアログには入りません。そこには英数字で入力するか、貼り付けてください。
- **音は出ません**：VNC は音を運びません。
- **ページの描画は CPU で行います**（`--disable-gpu`）。動きの多いページや動画は、host の CPU と手元までの通信を使います。
- **DSH Desktop** には対応していません。タブは Web ブラウザで開いた DSH が必要です。

## ブラウザでの確認

Xvnc と Chromium を `PATH` に置いて、リポジトリのルートで `pnpm dev`：

1. 会話で右サイドバーから **ブラウザ** を開きます。**ブラウザを起動しています…** のあと、タブ列とアドレスバーのある Chromium のウィンドウが出ます。
2. アドレスバーにアドレスを入力して Enter を押すと、ページが開きます。
3. ページの入力欄をクリックし、IME で日本語を入力します。変換中の文字が入力欄のところに出て、確定した文字が入力欄に入ります。
4. 手元でコピーした文字を、入力欄で Ctrl+V で貼り付けられます。ページの文字を選んで Ctrl+C を押すと、手元のクリップボードに入ります。
5. ページからファイルをダウンロードすると、タブにお知らせが出て、**保存** で手元に保存できます。ファイル選択の入力欄をクリックすると、タブに **選ぶ…** が出て、選んだファイルがページに届きます。
6. サイドバーを分割して、新しい側で **ブラウザ** を開きます。新しいタブに画面が移り、元のタブには **このタブを表示** が出て、押すと画面が戻ります。
7. モデルにページを開いて内容を教えるよう頼みます。会話が full access でなければアドレスを開く許可を求め、スクリーンショットを撮ってページを説明します。ページは表示中のタブに映ります。
8. ウィンドウの最後の Chromium のタブを Ctrl+W で閉じると、ブラウザタブに新しい空のウィンドウが出ます。
9. 会話を archive すると、そのウィンドウが閉じます。表示中のブラウザタブがなければ、`idleMinutes` のあとにブラウザが止まります。
