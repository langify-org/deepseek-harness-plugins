# @langify-org/dsh-browser

[English](README.md) | [日本語](README.ja.md) | 中文

在 DeepSeek Harness 主机上运行的真正的 Chromium，由你和模型共享。右侧边栏的 **浏览器** 标签页实时显示它的窗口：你可以像使用任何浏览器一样在其中浏览，模型则通过 `browser_*` 工具操作同样的窗口。浏览器运行在主机上，因此即使没有打开 DSH 页面，模型也能继续使用它，并且所有对话共享它的登录状态。

## 要求

- 在网页浏览器中使用的 DSH `>=0.2.2-rc.1 <0.3.0-0`（DSH Web）。
- DSH 主机为 Linux 或其他 X11 系统，并装有：
  - [TigerVNC](https://tigervnc.org) 的 `Xvnc`，位于 `PATH` 中或由 `xvnc` 设置指定。
  - Chromium 或 Google Chrome，以 `chromium` 之名位于 `PATH` 中或由 `chromium` 设置指定。
  - 所访问页面需要的字体，例如中日文用 Noto Sans CJK、表情符号用 Noto Color Emoji。缺少的字符显示为方框。

缺少 Xvnc 或 Chromium 时，标签页会说明缺少哪一个。

## 安装

```sh
dsh plugin --profile <profile> add @langify-org/dsh-browser
```

在 DSH Web 中，也可以从 **Plugins** 页面添加。

## 设置

| 设置          | 默认值                               | 含义                                                                         |
| ------------- | ------------------------------------ | ---------------------------------------------------------------------------- |
| `xvnc`        | `Xvnc`                               | Xvnc 可执行文件：`PATH` 中的名称或路径                                       |
| `chromium`    | `chromium`                           | Chromium 可执行文件：`PATH` 中的名称或路径                                   |
| `flags`       | `--disable-gpu`                      | 追加在插件自带参数之后的命令行参数                                           |
| `language`    | 空                                   | Chromium 自身菜单和页面的语言（`LANGUAGE`），例如 `ja`；为空则沿用主机的设置 |
| `stateDir`    | `<DSH home>/browser`（bundle layer） | 存放配置文件、下载和上传文件的位置                                           |
| `idleMinutes` | `30`                                 | 没有显示中的浏览器标签页且无人使用达到这么多分钟后停止浏览器；`0` 表示不停止 |

## 使用

从右侧边栏打开 **浏览器**。每个浏览器标签页对应一个 Chromium 窗口，带有 Chromium 自己的标签页、地址栏和菜单。在任何对话中都可以打开任意多个。

- **只有一个屏幕**：所有窗口共享一个屏幕，屏幕上显示的是最后显示的浏览器标签页的窗口。其他正在显示的浏览器标签页会说明这一点，并提供 **显示这一个**。切换到某个对话或标签页时，会显示它的窗口。
- **大小**：窗口采用标签页的大小，调整侧边栏宽度时也会跟随。Chromium 窗口至少宽 500 像素；更窄的标签页可以横向滚动。
- **输入中文、日文等语言**时使用你设备上的输入法：照常输入，确认后的文字会输入到页面中获得焦点的输入框。其他按键（包括快捷键）作为按键发送给 Chromium。
- **剪贴板**：Ctrl+V（Cmd+V）粘贴你设备上的剪贴板。在 Chromium 中复制的内容会进入你设备的剪贴板；如果浏览器拒绝写入，标签页会提供 **复制** 按钮。
- **下载**：下载完成后，所在窗口的标签页会显示通知，用 **保存** 可以保存到你的设备上。主机会保留文件，直到浏览器下次启动。
- **上传**：页面需要文件时，所在窗口的标签页会提供 **选择…**，用来选择你设备上的文件，页面会收到这些文件。
- **登录状态**保存在所有对话共享的一个 Chromium 配置文件中：在任意标签页登录一次即可。
- **关闭**：关闭浏览器标签页会关闭它的窗口，归档对话会关闭该对话的窗口。关闭窗口中最后一个 Chromium 标签页时，对应的浏览器标签页会得到一个新的空白窗口。
- **停止**：浏览器在标签页或模型第一次需要时启动，在没有显示中的浏览器标签页且无人使用达到 `idleMinutes` 后停止。窗口随之结束，登录状态会保留。

模型得到的内容：

- **系统提示词**说明共享的浏览器和这些工具。
- **工具**操作对话最后使用的窗口，或调用时用 id 指定的窗口：

| 工具                 | 作用                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| `browser_windows`    | 列出对话的窗口及其中的标签页：工具默认使用哪一个，哪一个显示在你的屏幕上         |
| `browser_open`       | 打开一个地址；对话没有窗口或要求时在新窗口中打开，由下一个打开的浏览器标签页显示 |
| `browser_screenshot` | 页面的图像，供模型查看；需要能接收图像的模型                                     |
| `browser_click`      | 点击 CSS 选择器找到的元素，或某个位置                                            |
| `browser_type`       | 向获得焦点的输入框输入文字，任何语言均可                                         |
| `browser_key`        | 按住修饰键按下某个键，例如 Enter 或 Control+A                                    |
| `browser_eval`       | 在页面中执行 JavaScript 并返回其 JSON 值                                         |

下载的文件也保存在 `<stateDir>/downloads/<id>/` 中，模型可以读取。

## 安全

- **浏览器在沙箱外运行**，因此会改变页面的工具（`browser_open`、`browser_click`、`browser_type`、`browser_key`、`browser_eval`）需要与沙箱外命令相同的许可：对话拥有完全访问权限时立即执行，否则会先询问你。列出窗口和截图无需询问。无法询问的子代理只能在完全访问权限下改变页面。
- **你的登录状态也属于模型**：模型使用同一个配置文件，在你登录过的地方处于登录状态。只在你愿意让模型以你的身份操作的地方登录。
- **页面上的一切对模型都是可见的**，在模型读取页面时。
- **标签页的连接**与 DSH 自己的 API 请求一样经过检查：只有已登录此 DSH 的浏览器才能看到屏幕或发送输入。VNC 只在仅你的用户可以进入的目录中的 unix 套接字上监听，不在任何网络端口上监听。
- **Chromium 的 DevTools 端口**按远程调试的要求，在 `127.0.0.1` 上由 Chromium 选择的端口监听：主机上的其他程序，包括其他用户的程序，都可以连接并控制浏览器。请在只有你使用的主机上使用本插件。
- **环境变量**：与 DSH 自己的子进程一样，Xvnc 和 Chromium 获得的是去掉名称包含 `KEY`、`PASSWORD`、`SECRET` 或 `TOKEN` 的变量以及 `DSH_*` 后的 DSH 环境。

## 工作原理

主机端插件运行 `Xvnc`（TigerVNC），一个通过 unix 套接字以 VNC 提供屏幕的虚拟 X 服务器，并在该屏幕上运行 Chromium，使用 `stateDir` 中的配置文件、`--no-startup-window`，以及由 Chromium 选择的 DevTools 端口。它通过 Chrome DevTools Protocol 为每个浏览器标签页创建一个窗口，把最后显示的标签页的窗口提到最前并调整为标签页的大小，用 `Input.insertText` 输入确认后的文字，保存下载，并接管页面的文件选择（`Page.setInterceptFileChooserDialog`）。模型的工具使用同一个连接。

浏览器端加入 **浏览器** 标签页。屏幕用固定版本并随插件打包的 [noVNC](https://github.com/novnc/noVNC) 绘制，通过专用的 WebSocket（`/langify-browser/vnc`）由主机转发给 Xvnc；noVNC 会把 Xvnc 的屏幕调整为标签页的大小。另一个 WebSocket（`/langify-browser/control`）传递标签页的请求（显示、大小、确认后的文字）和主机的通知（是否显示在屏幕上、下载、文件选择）。键盘输入经过屏幕上方的输入框，因此可以使用设备的输入法：按键经 noVNC 转换后通过 VNC 发送，确认后的文字通过 control 通道发送。下载、上传和关闭窗口使用 DSH API 通道上的固定路由。DSH 以 CommonJS 加载浏览器端插件，无法容纳 noVNC 中唯一的顶层 `await`（检测能否解码 H.264），因此构建时会把它改写为 Promise；如果 noVNC 改动了这一行，构建会失败。

## 已知限制

- **只有一个屏幕**：两个浏览器标签页或两台设备无法同时显示不同的窗口。
- **页面以弹出方式打开的窗口**（指定大小的 `window.open`，例如登录弹窗）会出现在当前显示的标签页的屏幕最上层，没有可用于移动的边框。页面关闭它们时会关闭，也可以按 Ctrl+W 关闭。
- **输入法确认后的文字只会进入页面**，不会进入 Chromium 的地址栏、菜单或对话框：在那里请用拉丁字母输入，或者粘贴。
- **没有声音**：VNC 不传输音频。
- **页面用 CPU 渲染**（`--disable-gpu`）：动态较多的页面和视频会消耗主机的 CPU 和到你设备的带宽。
- **不支持 DSH Desktop**：标签页需要在网页浏览器中打开的 DSH。

## 在浏览器中验证

在 `PATH` 中有 Xvnc 和 Chromium 的情况下，在仓库根目录运行 `pnpm dev`：

1. 在一个对话中从右侧边栏打开 **浏览器**。显示 **正在启动浏览器…** 之后，出现带有标签栏和地址栏的 Chromium 窗口。
2. 在地址栏输入地址并按 Enter：页面打开。
3. 点击页面中的输入框，用输入法输入中文或日文：正在输入的文字显示在输入框处，确认后的文字出现在输入框中。
4. 在你的设备上复制文字，在输入框中按 Ctrl+V：文字被粘贴。选中页面中的文字并按 Ctrl+C：文字进入你设备的剪贴板。
5. 从页面下载一个文件：标签页显示通知，用 **保存** 可以保存到你的设备上。点击文件输入框：标签页提供 **选择…**，选择的文件会到达页面。
6. 拆分侧边栏，在新窗格中打开 **浏览器**：它占用屏幕，第一个标签页提供 **显示这一个**，点击后屏幕回到它。
7. 让模型打开一个页面并说明内容。除非对话拥有完全访问权限，模型会先请求打开地址的许可，然后截图并描述页面；页面显示在正在显示的标签页中。
8. 在窗口中用 Ctrl+W 关闭最后一个 Chromium 标签页：浏览器标签页得到一个新的空白窗口。
9. 归档对话：它的窗口关闭。没有显示中的浏览器标签页时，浏览器在 `idleMinutes` 后停止。
