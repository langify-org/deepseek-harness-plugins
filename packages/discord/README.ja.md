# @langify-org/dsh-discord

[English](README.md) | 日本語 | [中文](README.zh.md)

Discord から DeepSeek Harness と会話します。指定したチャンネルに投稿すると、そのメッセージからスレッドが作られ、対応する DSH のセッションが始まります。スレッドがそのまま 1 つの会話です。返答・ツールの承認・エージェントからの質問はスレッドに届き、ボタンで答えます。

## 必要なもの

- DSH `>=0.2.1-rc.3 <0.3.0-0`。Web 構成で動かします（そのセッションコントローラーを使います）。
- このプラグイン専用の、ボットを持つ Discord アプリケーション。プラグインはアプリケーションのグローバルなスラッシュコマンドを自分のものに置き換えます。

## Discord の準備

1. [Developer Portal](https://discord.com/developers/applications) でアプリケーションを作り、**Bot** を開きます。トークンを再発行して控えます。**Message Content Intent** を有効にします。ボットへの mention を含まないスレッド内のメッセージを読むために必要です。利用者が 10,000 人未満なら、有効にするだけで使えます。
2. スコープ `bot` と `applications.commands`、次の権限でボットをサーバーに招待します: View Channels、Send Messages、Send Messages in Threads、Create Public Threads、Read Message History、Add Reactions（権限の整数は `309237713984`）。

   ```
   https://discord.com/oauth2/authorize?client_id=<application id>&scope=bot+applications.commands&permissions=309237713984
   ```

3. Discord で **開発者モード**（設定 → 詳細設定）を有効にし、自分のユーザー ID と、使うチャンネルの ID をコピーします。

## 導入

```sh
dsh plugin --profile <profile> add @langify-org/dsh-discord
```

DSH の Web 版や Desktop 版では **Plugins** ページから追加できます。

ボットのトークンを `tokenEnv` の名前（既定は `DISCORD_BOT_TOKEN`）で DSH に渡します。資格情報として保存するか、DSH を起動する環境の環境変数に設定します。続けてプラグインを設定します。

```yaml
- id: langify-discord
  name: '@langify-org/dsh-discord'
  config:
    userId: '123456789012345678'
    channels:
      - channelId: '234567890123456789'
        cwd: /home/me/project
```

## 設定

| 設定       | 既定値              | 意味                                                                                                                                    |
| ---------- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `tokenEnv` | `DISCORD_BOT_TOKEN` | ボットのトークンを持つ資格情報の名前。保存された資格情報が環境変数より優先されます。                                                    |
| `userId`   | 空                  | 自分の Discord ユーザー ID。プラグインはこのユーザーの発言だけを受け付け、ボタンもこのユーザーだけが押せます。必須です。                |
| `channels` | `[]`                | 新しい投稿でセッションを始めるチャンネル。`channelId` と、セッションの作業フォルダー `cwd`。`cwd` の Workspace があればそこに入ります。 |

## 使い方

- **会話を始める**: 設定したチャンネルに投稿します。ボットがそのメッセージからスレッドを作り、`discord-<スレッド ID>` という名前の DSH セッションを始めます。セッションは DSH にも表示され、どちらからでも続けられます。
- **続ける**: スレッドに投稿します。エージェントが作業中なら、DSH と同じくセッションの待ち行列に入ります。
- **進み具合**: 自分のメッセージに 👀 が付けば受け付け済みです。エージェントが動いている間は、ボットが入力中と表示されます。ターンが終わると、印が ✅（完了）、⏹️（停止）、❌（失敗。エラーをスレッドに書きます）、⚠️（出力の上限）、⛔（ブロック）に変わります。
- **返答**: エージェントのメッセージを 1 通ずつスレッドに投稿します。2,000 字で、コードブロックを壊さずに分けます。
- **止める**: スレッドで `/stop` を使うと、動いているターンを止めます。待ち行列のメッセージは残ります。
- **承認**: ツールに承認が要るとき、スレッドに **Allow** と **Deny** が出ます。Allow はその 1 回だけに効きます。
- **質問**: `ask_user_question` の質問を 1 問 1 メッセージで出します。選択肢ごとのボタン（複数選択はメニュー）と、自由入力の **Other…** があります。計画のレビューでは先に計画を表示します。答える前に質問の待ち時間が切れても、スレッドか DSH から答えられます。
- **添付**: PNG・JPEG・WebP・GIF の画像は、モデルが画像を受け付けるならメッセージと一緒にモデルに渡します。それ以外のファイルはリンクで渡します。

## 仕組み

- ボットは DSH から Discord の Gateway に接続します。DSH に公開アドレスは要りません。
- 投稿は、DSH Web のプロンプトと同じセッションコントローラーを通ります。メッセージ ID をリクエスト ID にするので、同じメッセージが 2 回届いても 1 回しか入りません。
- ID が `discord-` で始まるセッションを橋渡しします。そのセッションの返答をスレッドに投稿し、承認と質問には DSH 自身のダイアログより先に答えます。他のセッションには触れません。
- 承認や質問が来たときに Discord に届かない場合や、待っている間にプラグインが外された場合は、DSH 自身のダイアログが引き継ぎます。

## セキュリティ

ボットが読めるチャンネルに `userId` として投稿できる人は、あなたの DSH の権限でエージェントを動かせます。シェルも含みます。その Discord アカウントを守り（二要素認証）、サーバーは非公開にし、ボットのトークンはパスワードとして扱ってください。他のユーザーやボットの投稿は無視し、ボットの投稿は誰にも mention しません。[SECURITY.ja.md](../../SECURITY.ja.md) も読んでください。

## 手動確認

Discord のボットが要るので `pnpm check` には含めていません。`pnpm dev` で実行します。`userId` と `channels` は `package.json` の隣の `dev.patch.yml` に書き（コミットしない）、トークンは `.envrc.local` に書きます。

1. 設定したチャンネルへの投稿でスレッドができて 👀 が付き、返答がスレッドに届き、印が ✅ になる。セッションが DSH に表示される。
2. スレッドへの 2 通目が同じセッションに続く。他のユーザーの投稿には何も付かない。
3. 承認を有効にした状態（`policy: ask`）で、シェルのコマンドに **Allow**/**Deny** が出て、それぞれ期待どおりのツール結果になる。
4. 選択肢つき・複数選択・**Other…** の `ask_user_question` が、選んだ答えを返す。計画のレビュー（`exit_plan_mode`）で計画と選択肢が出る。
5. 長いターンの途中の `/stop` でターンが止まり、印が ⏹️ になる。
6. スレッドに貼った画像がモデルに届く。
7. 質問を待っている間にプラグインを再読み込みすると、質問が DSH に移る。

## 既知の制限

- DSH が止まっている間の投稿は、後から読みません。
- 橋渡しするのはボットが作ったスレッドだけです。自分で作ったスレッドは無視します。
- 返答はモデルのステップ単位で届きます。トークン単位のストリーミングはなく、ツールの呼び出しは表示しません。
- サブエージェントからの承認と質問は DSH で答えます。
- リアクションはプラグインが動いている間に始まったターンにだけ付きます。再起動したとき実行中だったターンには印が付きません。
- 画像以外の添付のリンクは、Discord 側でしばらくすると切れます。
