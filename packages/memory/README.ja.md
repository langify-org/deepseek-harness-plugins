# @langify-org/dsh-memory

[English](README.md) | 日本語 | [中文](README.zh.md)

DeepSeek Harness に記憶を持たせます。記憶はディレクトリで、記録係のエージェントがすべての会話から更新し、すべての会話に渡されます。記録係は **memory** ワークスペースで働くので、何をなぜ記憶したかを見られます。変更はすべて git の commit なので、取り消せます。

## 必要なもの

- Web 版（記憶の会話を作るのに使います）と、プロセス内のサブエージェントのある DSH `>=0.2.2-rc.2 <0.3.0-0`。
- ホストの `PATH` にある [`git`](https://git-scm.com)。

## 導入

```sh
dsh plugin --profile <profile> add @langify-org/dsh-memory
```

DSH の Web 版や Desktop 版では **Plugins** ページから追加できます。

## 設定

| 設定               | 既定値             | 何か                                                     |
| ------------------ | ------------------ | -------------------------------------------------------- |
| `directory`        | `$DSH_HOME/memory` | 記憶のディレクトリ                                       |
| `git`              | `git`              | git の実行ファイル。`PATH` から探す名前か、パス          |
| `timeZone`         | ホストのもの       | 記憶の会話の日を決める IANA のタイムゾーン               |
| `dayStartsAt`      | `3`                | 新しい記憶の会話で日が始まる時刻（時）                   |
| `subagentProvider` | `spawn`            | 記録係を起動するサブエージェントの provider              |
| `toolArguments`    | `300`              | 記録係が読む、ツール呼び出しの引数の文字数               |
| `toolResult`       | `500`              | 記録係が読む、ツールの結果の文字数                       |
| `indexLines`       | `200`              | 会話の開始時に渡す `MEMORY.md` の行数                    |
| `indexBytes`       | `25600`            | 会話の開始時に渡す `MEMORY.md` のバイト数                |
| `rebaselineAfter`  | `20`               | この数を超える commit があったら、`MEMORY.md` を渡し直す |

## 仕組み

起動すると、記憶のディレクトリを git リポジトリとして作り、2 つのファイルを置きます。すでにあるファイルはそのままにします。

- `AGENTS.md`：記憶が何のためにあるか。DSH はこのディレクトリで働くすべての会話にこれを渡すので、記憶係に何が大事かを伝える場所になります。書いてあるのは記憶の目的で、記憶のしかたではありません。強いモデルは、何を残すかを自分で判断したほうがよく覚えるためです。
- `MEMORY.md`：記憶していることの索引。

また、このディレクトリを **memory** ワークスペースとして登録します。

### 書く

memory ワークスペースには、1 日に 1 つ記憶の会話（**Memory · YYYY-MM-DD**）があり、その日に初めて使うときに作ります。日は `dayStartsAt` に始まります。記憶の会話そのものは動きません。その日の記録係を入れておくだけです。

会話のターンが終わると、プラグインはその日の記憶の会話のサブエージェントとして記録係を起動し、その会話のまだ記録していない部分を渡します。一度も記録していない会話（プラグインを入れる前からある会話など）は、終わったばかりのターンから読みます。記録係が読むのは、ユーザーとモデルが言ったこと、ツールの呼び出し、各結果の先頭です。モデルの推論と、DSH が差し込んだ文脈（指示のファイル、スキル、通知）は含めません。記録係は毎回、記憶のディレクトリのほかは何もない状態から始めるので、ある会話で言われたことが、別の会話の記憶に混ざりません。

記録係は一度に 1 つだけ働き、その間に終わったターンは待ちます。記録係が終わると、ディレクトリの変更をすべて commit します。commit メッセージは記録係の返答で、元の会話を示す `Memory-Source: <session id>` の trailer を付けます。何も変えなかった記録係は commit しません。最後まで終わらなかった記録係の分は、その会話の次のターンで読み直されます。

サブエージェントの会話と、memory ワークスペースの会話は記録しません。memory ワークスペースで記録係以外の会話（そこで記憶を直接直すときなど）のターンが終わると、その返答をメッセージにして commit します。

### 読む

ターンの最初に、会話に記憶を渡します。

- 初めてのときは、`MEMORY.md` の先頭（`indexLines` と `indexBytes` まで）とその版。
- その後は、記憶が変わったときに、それ以降の commit のメッセージ。その会話だけが元になった commit は除きます。
- 渡してから `rebaselineAfter` を超える commit があったときや、compaction で見えなくなったときは、`MEMORY.md` をもう一度。

サブエージェントの会話と、memory ワークスペースの会話には渡しません。

## 安全性

記録係は、既定のプリセットと記憶の会話の権限で記憶のディレクトリで働く、ふつうの DSH のサブエージェントです。すべての会話が、そこに打ち込んだものも含めて記録係に送られます。`AGENTS.md` で秘密を書かないよう伝えていますが、commit を確かめてください。止めるには **Plugins** ページでプラグインを無効にします。何も消えません。記憶のディレクトリ、記憶の会話、ワークスペースは残ります。
