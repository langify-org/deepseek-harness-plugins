# @langify-org/dsh-memory

[English](README.md) | [日本語](README.ja.md) | 中文

为 DeepSeek Harness 提供记忆：一个目录，由记录员代理根据每个对话保持更新。记录员在 **memory** 工作区中自己的对话里工作，因此你可以看到它记住了什么以及原因；每次改动都是一个可撤销的 git 提交。

这是第一阶段：记忆会被写入，但对话还不会读取它。

## 要求

- 带 Web 应用的 DSH `>=0.2.2-rc.1 <0.3.0-0`（用于创建记录员的对话）。
- 主机 `PATH` 中的 [`git`](https://git-scm.com)。

## 安装

```sh
dsh plugin --profile <profile> add @langify-org/dsh-memory
```

在 DSH 的 Web 版和 Desktop 版中，可以从 **Plugins** 页面添加。

## 设置

| 设置            | 默认值             | 说明                                         |
| --------------- | ------------------ | -------------------------------------------- |
| `directory`     | `$DSH_HOME/memory` | 记忆目录                                     |
| `git`           | `git`              | git 可执行文件：在 `PATH` 中查找的名称或路径 |
| `timeZone`      | 主机的时区         | 按天划分记录员对话所用的 IANA 时区           |
| `toolArguments` | `300`              | 记录员读取的工具调用参数的字符数             |
| `toolResult`    | `500`              | 记录员读取的工具结果的字符数                 |

## 工作方式

启动时，插件将记忆目录创建为 git 仓库并放入两个文件，已存在的文件保持不变：

- `AGENTS.md`：记忆的用途。DSH 会把它交给在该目录中工作的每个对话，因此这里是告诉记忆代理什么对你重要的地方。它说明记忆的用途，而不是记忆的方法：强大的模型自己判断什么值得保留时，记得更好。
- `MEMORY.md`：已记住内容的索引。

插件还会将该目录注册为 **memory** 工作区。

当某个对话的一轮结束时，插件会把记录员尚未读过的部分发送到当天的记录员对话（memory 工作区中的 **Memory scribe · YYYY-MM-DD**），没有则新建。记录员读取的是你和模型说的话、工具调用以及每个结果的开头；模型的推理和 DSH 注入的上下文（指令文件、技能、通知）不包括在内。子代理的对话和 memory 工作区中的对话不会被发送。记录员工作期间到达的请求会等待，并一起读取。

当 memory 工作区中任何对话的一轮结束时，插件会提交目录中的所有改动。提交信息就是结束该轮的回复，并为该轮读取的每个对话附上 `Memory-Source: <session id>` 尾注。没有任何改动的轮次不会产生提交。

## 安全

记录员是一个普通的 DSH 对话，使用默认预设及其权限，在记忆目录中工作。每个对话都会发送给它，包括你在其中输入的任何内容；`AGENTS.md` 要求它绝不写入机密，但请检查它的提交。要停止它，请在 **Plugins** 页面禁用插件。不会删除任何东西：记忆目录、记录员的对话和工作区都会保留。
